# JGebra

**JGebra** is a lightweight project created for a school mathematics course.  
Please note that the code may be a bit rough or incomplete, as it was written quickly to meet school deadlines. Nevertheless, it is functional and still under development.

## ✨ Upcoming Features

- Support for functions of the form `x = f(y)`
- Full support for parentheses `()` in expressions

## 📌 Usage

JGebra offers a simple and intuitive interface.  
To plot a function, use the **Add Function** section on the side panel.

## 📊 Example Function Inputs

| Input Expression | Description                      | Notes                     |
|------------------|----------------------------------|---------------------------|
| `y = x^2`        | Quadratic function               | Parabola opening upward   |
| `y = sin(1x)`    | Sine wave                       | Periodic function         |
| `y = 2x + 3`     | Linear function                  | Straight line             |
| `y = x^3 - x`    | Cubic function                   | With turning points       |
